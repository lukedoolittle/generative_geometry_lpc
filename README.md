# Lagrangian Predictive Coding

## Install

Python 3.9 or newer.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```



## Train

From the repository root, train an identity chain on synthetic regression
generated by a frozen teacher network with the same sizes:

```bash
python -m lpc
```

That command also runs inference on a held-out batch and prints the forward
MSE, the Lagrangian, and the constraint residual.

From Python, one Algorithm 1 pass is `Network.train`. `T` is the inference
budget, `eta_h` the primal step size, `alpha` the dual rate, `rho` the penalty,
and `eta_theta` the weight step size. Multipliers are reset to zero on every
batch, as in the algorithm.

```python
from lpc import Network

net = Network((2, 8, 1), activation="identity", seed=0)
# x: (batch, 2), y: (batch, 1)
losses = net.train(x, y, steps=20, T=16, eta_h=0.08, alpha=1.0, rho=1.0, eta_theta=0.05)
```

`losses[0]` is the feasible-forward mean squared error before any update.
Later entries are that same forward loss after each learning step.

## Inference

Inference does not change weights. It initializes activities on the forward
pass, then runs `T - 1` primal-dual cycles and a final primal step.

```python
result = net.infer(x, y, T=16, eta_h=0.08, alpha=1.0, rho=1.0)
result.hiddens       # h_1 .. h_{L-1} after the final primal step
result.multipliers   # λ_1 .. λ_{L-1} after the last dual step
result.residuals     # r_i = h_i - σ(W_i h_{i-1}) at the final activities
result.prediction    # W_L h_{L-1} using those activities
result.energy        # batch-mean augmented Lagrangian
```

`alpha = 0` freezes the multipliers at zero and recovers finite-inference
predictive coding. `T = 1` is a single predictive-coding activity step.

## Tests

```bash
pytest
```

The tests check that a primal step descends the augmented Lagrangian, that the  
dual variable integrates the residual, that linear inference reaches the  
backprop adjoint of Figure 1, and that a short training run reduces forward loss.
